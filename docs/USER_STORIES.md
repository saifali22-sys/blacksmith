# User Stories

These stories illustrate the platform requirements from the users' perspective to guide the development process.

## Customer / Guest

* As a customer, I want to browse the homepage, so I can see an overview of the platform and the latest added works.
* As a customer, I want to browse works divided by categories (doors, windows, etc.), so I can smoothly reach the models I am looking for.
* As a customer, I want to search for a work or a workshop using the search bar, so I can reach the result faster.
* As a customer, I want to use filters (like city, design, price), so I can narrow down the displayed results based on my needs.
* As a customer, I want to open a work details page and flip through pictures, so I can inspect the details and craftsmanship of the work.
* As a customer, I want to view specifications details (dimensions, materials), so I can understand the nature of the displayed work.
* As a customer, I want quick access to the contact number or WhatsApp link of the business owner, so I can contact them to execute the model.
* As a customer, I want to access the workshop profile, so I can see all works of this workshop, their ratings, and the variety of their work.
* As a customer, I want the ability to report a post containing fake pictures or abusive content, so I can contribute to keeping the platform clean.

## Workshop Owner / Blacksmith

* As a workshop owner, I want to create a new account using my phone number or email, so I can display my works.
* As a workshop owner, I want to log in to my special dashboard, so I can manage my posts and pictures.
* As a workshop owner, I want to fill in my workshop data (name, logo, description, city), so my profile looks professional to customers.
* As a workshop owner, I want to add a new work specifying its type and specifications, so I can attract visitors interested in this type of work.
* As a workshop owner, I want to upload several pictures for a single work, so I can highlight its details from several angles.
* As a workshop owner, I want to hide the price and use a "Price on Demand" option, because sometimes the price varies based on the customer's house dimensions.
* As a workshop owner, I want to edit or delete any work I have published, in case I find a mistake or wish to remove it from display.

## Administrator

* As an admin, I want to log in to a secure Admin Dashboard, so I can manage the platform.
* As an admin, I want to manage categories, so I can add new work types like "Metal Furniture" when needed.
* As an admin, I want to see a list of all registered workshop owners, so I can track their activity.
* As an admin, I want to be able to ban any account that manipulates or violates platform terms, so I can protect the customers.
* As an admin, I want to review reports received from visitors, so I can take action against violating posts.
* As an admin, I want a general statistics dashboard showing platform and content growth, so I can measure the success of the project.
